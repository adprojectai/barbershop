# Куда положить свои фото

Сайт работает и без фото — вместо них показываются оформленные тёмные заглушки
с подписью имени файла. Как только вы положите файл с нужным именем в эту папку,
он подставится автоматически (обновите страницу в браузере).

| Файл | Где используется | Что снять |
|---|---|---|
| `hero.jpg` | Фон первого экрана (hero) | Общий widescreen-кадр интерьера, желательно тёмный, с подсветкой полок |
| `about.jpg` | Блок «О салоне» | Один из рабочих экранов / кресло крупным планом |
| `bar.jpg` | Галерея «Пространство» | Барная стойка с подсвеченными полками |
| `stations.jpg` | Галерея «Пространство» | Ряд рабочих мест / зеркал |
| `lounge.jpg` | Галерея «Пространство» | Зона с люстрой и креслами для ожидания |
| `door.jpg` | Галерея «Пространство» | Входная дверь с вывеской «PK MEN'S SALON» |
| `facade.jpg` | Галерея «Пространство» | Фасад здания снаружи |
| `products.jpg` | Галерея «Пространство» | Полка с продукцией для стайлинга |
| `pio.jpg` | Команда | Портрет 피오 원장 (квадратный кадр, лицо в центре) |
| `eunseong.jpg` | Команда | Портрет 은성 실장 (квадратный кадр) |

**Формат:** JPG или PNG, любое разрешение — CSS обрежет их под нужную форму
(`object-fit: cover`). Для быстрой загрузки лучше не крупнее ~1600px по длинной
стороне и до ~500 КБ на файл.
